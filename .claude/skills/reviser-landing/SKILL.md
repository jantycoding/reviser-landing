# Reviser — лендинг

Vite + React 19 + Tailwind v4 (без конфига, токены в `@theme` внутри `src/index.css`).
Весь текст страницы — в `src/content/site.js`. Компоненты текст не содержат.

## Что продаём (не перепутать)

Продукт — **внедрение ИИ-агентов в бизнес**. Разбор за 9 900 ₸ — первое касание
и основной источник дохода, а не отдельный продукт диагностики.

Порядок секций — это воронка, менять его без причины нельзя:

```
Hero      обещание без цены, по центру, без чат-демо (см. «Hero» ниже)
Agents    8 сценариев — главный разогрев, сердце страницы
Platforms лента интеграций (НЕ логотипы клиентов)
Gate      «агент наугад — дорогая игрушка» → поворот к разбору
Audit     что входит в разбор, что на выходе
Report    панель с примером отчёта (AgentSwarm — бригада «клодиков»)
Process   5 шагов, час времени, оплата → код → агент
Pricing   9 900 · 6 900 · от 600 000
Faq       снятие возражений
Checkout  оплата Kaspi на странице
```

Цена впервые появляется в блоке Gate. С 06.08.2026 (третий редизайн за
день, решение владельца) кнопка в шапке (`headerCta`) цену не показывает —
только «Получить разбор», без цифр, не жирным, без градиента (`bg-signal-flat`
в `index.css`). Раньше здесь была цена — не возвращать без запроса.

## Hero — редизайн 06.08.2026 (второй за день), решение владельца

- **Без чат-демо.** Компонент и данные (`ChatDemo`, `hero.chat`) удалены из
  `Hero.jsx` и `site.js`. Не восстанавливать по памяти из старых версий.
- Всё по центру одной колонкой, не асимметричный грид.
- Фон — `FloatingLines` (`components/reactbits/FloatingLines.jsx`, WebGL/
  **three**), не `Orb` и не `GradientWaves` (оба остаются в кодовой базе
  неиспользуемыми, как `Aurora`/`ElectricBorder`). Палитра линий — серебро →
  белый → тёмная синева, не дефолтные розовый/синий из исходника react-bits.
- Абзац под заголовком — один связный подзаголовок (`hero.subtitle`), не
  список пилюль (`hero.pills` убран). `hero.secondaryNote`/`hero.pivotNote`
  тоже убраны с главной (тот же день) — не восстанавливать без запроса.
- Заголовок — **без градиента и без пер-строчного акцента**, обе строки одним
  цветом (`text-chalk`), шрифт `font-display` (Unbounded), не `font-sans`.
  `SplitText` — `splitType="words"`, **не** `"chars"`: у Unbounded глиф шире,
  чем у Inter, и при переносе ВНУТРИ одного посимвольно-разбитого таргета
  атомарные inline-block-боксы букв налезали друг на друга между строками
  (не только на узком экране — на 1440px тоже). Слова как целые блоки
  переносятся браузером нормально.
- Словесный знак — **`Reviser`**, без приставки «ai», тонкий начерк
  (`font-light`), не `reviser.ai` строчными и не `font-semibold`.
- Логотип (`components/ui/Logo.jsx`) — неровный пятиугольник («клодик»,
  свёрнутый в геометрическую метку), серебристо-металлический градиент, не
  три узла с линиями и не пиксель-арт клодик. Клодик-маскот остаётся в
  `components/agents/Claudik.jsx` для демо-панели отчёта — два разных знака
  для двух разных мест.
- Навигация в шапке — плавающая капсула (`rounded-full`, поля по бокам от
  края вьюпорта), не сплошная полоса.

React Bits компоненты: `FloatingLines` подключён (см. выше). `Aurora` — уже
существовал неиспользуемым, оставлен как есть (запрошенные цвета конфликтуют
с монохромной палитрой). `ScrollStack` подключён 06.08.2026 (третий редизайн
за день) в `Agents.jsx` — карточки сценариев складываются в стек внутри своей
локальной прокручиваемой области. **Наша копия компонента
(`components/reactbits/ScrollStack.jsx`) не принимает `useWindowScroll`
вообще** — Lenis всегда привязан к локальному контейнеру, не к `window`,
именно чтобы не конфликтовать с ловушкой №1 ниже и со scroll-based логикой
Header/Reveal. `FoldText` тоже подключён тем же решением — эффект переворота
на заголовке Agents, `splitBy="word"` (не `"char"`, та же причина, что у
`SplitText` в Hero — см. «Анимации»). Подробности — `BRIEF.md` §3.3.

## Agents — редизайн 06.08.2026 (третий за день), решение владельца

- Вступительный абзац секции (`agents.subtitle`) и «мостик» в конце
  (`agents.bridge`) убраны из `site.js` — не восстанавливать без запроса.
- Строка «ВМЕСТО …» у каждой карточки (`item.replaces`) убрана — карточка
  теперь просто заголовок + абзац, без сравнения «было/стало».
- Карточки — в `ScrollStack`, не в решётке `grid`. Заголовок секции остаётся
  ВНЕ ScrollStack, как обычный элемент секции со своим `FoldText`-эффектом.

## Три цвета, больше не добавлять — палитра «Metal Noir»

| Токен | Значение | Роль |
|---|---|---|
| `ink` / `ink-2` / `surface` / `surface-2` / `line` / `line-2` / `mist` / `fog` / `chalk` | фон = чистый чёрный `#000000`, текст = белый `#ffffff` | нейтраль |
| `signal` / `signal-soft` | `#b9bec7` / `#e4e7ec` (серебро, с настоящим металлическим градиентом на заливках `bg-signal`) | действие, находки, акценты |
| `verify` | `#4d84bf` (профессиональная синева) | проверено, галочки, «работает» |
| `orchid` | `#2f5f8f` | декоративные градиенты (лого, FloatingLines) — **только декоративно** |

**Решение владельца, финальное (06.08.2026, второй редизайн за день) — не
откатывать. Отменяет «Midnight Mirage» от того же дня.** Палитра —
«Metal Noir»: чисто чёрный фон, серебристо-металлический акцент (с градиентом)
+ белый, плюс тёмная синева как второй акцент. Весь зелёный
(`#00804c`/`#74c365`/`#3fa06e`/`#a8c94a`) убран отовсюду, включая бригаду
«клодиков» в демо-отчёте (`site.js` → `report.crew`) и дефолтный цвет
`Claudik.jsx`. Если видишь зелёный, жёлтый (`#dbe64c`) или тёмно-синий фон
`#001f3f` где-либо кроме истории — ориентируйся только на актуальный
`src/index.css`. Палитра в этом проекте меняется по прямому запросу заказчика
чаще, чем в среднем проекте — смотри дату записи, самая свежая важнее
«финальности» пометки.

Кнопки — **тёмный текст на серебре** (`text-ink` на `bg-signal`), не
`text-white`: новый `bg-signal` — светлая заливка, белый текст на ней
проваливает контраст. Тени у кнопок — `rgba(185,190,199,…)` (серебро), не
старый зелёный `rgba(0,128,76,…)`.

## Типографика

Флюидная шкала в `@theme`: `text-label` `text-fine` `text-body` `text-lead`
`text-card` `text-h3` `text-h2` `text-h1` `text-metric`.

- Основной текст — `text-body` (15→17px). Ничего мельче `text-fine` в контенте.
- Инпуты формы — `text-body`. При 14px iOS Safari зумит страницу на фокусе.
- Абзацы — `max-w-[54ch]`…`[62ch]`.
- Вертикальный ритм — только `py-section` и `mt-stack` / `py-stack`.
  Никаких `py-20 md:py-28` вразнобой.

## Две ловушки, которые уже ломали сайт

### 1. Никогда не ставить `overflow-x` на `<html>`

`overflow-x: clip` или `hidden` на корне ломает нативный переход по якорям —
меню перестаёт скроллить страницу, хотя URL меняется. Горизонтальное
переполнение режется локально утилитой `clip-x` на конкретном контейнере
(бегущая строка, hero).

### 2. Имя spacing-токена не должно совпадать с ключевым словом `display`

В Tailwind v4 пространство имён `--spacing-*` порождает логическое свойство
`inline-<value>`. Токен `--spacing-block` сгенерировал вторую версию класса
`.inline-block` с `inline-size: 72px`, она перебила `display:inline-block`, и
каждый inline-block на странице получил ширину 72px — текст обрезался, слова
заголовка наезжали.

Запрещённые имена: `block`, `inline`, `flex`, `grid`, `table`, `contents`.
Поэтому токен называется `--spacing-stack`.

Проверка после изменения токенов:

```bash
npx vite build && grep -o "\.inline-block[^}]*}" dist/assets/*.css
# должна быть ровно одна строка: .inline-block{display:inline-block}
```

## Анимации

**Базовое состояние элемента — видимое.** Прятать имеет право только код,
который гарантированно покажет обратно.

Появление блоков — `components/ui/Reveal.jsx`: IntersectionObserver вешает
`is-armed` и `is-in`, дальше работает CSS-кейфрейм `rv-up`. Есть страховка на
1.8 с. GSAP-обёртка `AnimatedContent` была удалена именно потому, что таймлайн
рвался при быстром скролле и элементы навсегда застревали на `opacity: 0.3`.

**Решение владельца, финальное — не откатывать.** `gsap`, `SplitText` и
`three` **возвращены/добавлены в бандл по прямому запросу заказчика**:
`FloatingLines` (WebGL/**three**, с 06.08.2026, второй редизайн за день —
раньше был `Orb`, до этого `GradientWaves`) — фон первого экрана, `SplitText`
(GSAP, `splitType="words"` — см. ниже почему не `"chars"`) — заголовок `<h1>`
в `Hero.jsx`. Старая версия этого файла говорила «не возвращать» — то было ДО
того, как заказчик явно запросил эти эффекты в чате; не путать с текущим
состоянием. `FloatingLines` на узких экранах (≤767px) сам рисует один
статичный кадр без rAF-цикла (`animateOnNarrow=false` по умолчанию) — там
анимации нет по построению, лишний кадровый бюджет не тратится. `ogl` больше
не используется в Hero, но остаётся зависимостью — на нём всё ещё держится
неиспользуемый `Orb.jsx`/`GradientWaves.jsx`/`Aurora.jsx`.

Известный ложный сигнал №1: если QA-скрипт инжектит крупный `<style>` с
base64-шрифтами и сразу гоняет десятки синтетических `wheel`-событий подряд,
headless Chromium в песочнице (софтверный GL) иногда рисует всю страницу
одним тёмным прямоугольником — это артефакт связки в headless/software-GPU
окружении, не баг продукта. Обычная загрузка и скролл с реалистичными
паузами (или пауза ≥1с после инжекта шрифтов перед скроллом) рендерят
`FloatingLines`/`SplitText` корректно каждый раз, включая «прокрутить вниз →
вернуться наверх». Из react-bits, помимо этого, используются `SpotlightCard`,
`CountUp`, `ShinyText` — лёгкие, не прячут контент.

Известный ложный сигнал №2 (найден 06.08.2026 на Unbounded): если шрифт
инжектится через `page.addStyleTag` **после** первой отрисовки, а не через
настоящий `<link>` в `<head>` до монтирования React, `document.fonts.ready` в
`SplitText.jsx` может резолвиться со старыми метриками шрифта — GSAP считает
раскладку по неправильной ширине глифов, и часть текста в скриншоте выглядит
обрезанной/наложенной. В проде так не бывает (шрифт объявлен в `<link>` до
монтирования). Для честной проверки в headless — подменять сетевой запрос к
`fonts.googleapis.com` через `page.route(...).fulfill(...)` с локальным CSS
ДО `page.goto`, а не инжектить стиль постфактум.

Заголовок h1 не разбивать посимвольно (`splitType="chars"`), если фраза может
не поместиться в одну строку целиком: при переносе внутри одного таргета
атомарные inline-block-боксы букв налезают друг на друга между строками.
`splitType="words"` переносится нормально — слово остаётся целым блоком.

## Правила содержания

- **Лента логотипов — только платформы, к которым подключаемся.** Чужие бренды
  в роли своих клиентов ставить нельзя: политика Meta, товарные знаки, доверие.
- **Просим гостевой доступ на чтение, не пароли.** Это написано на сайте и это
  конкурентное преимущество.
- Нумерация `01 / 02 / 03` уместна только там, где порядок несёт смысл
  (`Process`). В карточках агентов и в `Gate` это декорация — не добавлять.

## Проверка после правок

```bash
npx vite build          # должно собраться без ошибок
npx vite preview        # затем прогнать страницу колесом сверху донизу
```

Смотреть: нет пустых экранов, `document.documentElement.scrollWidth === innerWidth`,
меню доскраливает до секции, на 390px заголовок не наезжает.
Для автоматической проверки использовать скилл `webapp-testing`.
