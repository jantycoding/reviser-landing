# Атрибуция

- **Источник:** https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling
- **Автор:** mattpocock
- **Лицензия:** см. LICENSE репозитория (MIT на момент установки)
- **Дата установки:** 2026-08-05
- **Зачем:** методика, которую запускает [[grill-me]]. Структурированное интервью
  «дерево решений» — задаёт вопросы раундами по «фронтиру» (решения, у которых уже
  settled все предпосылки), сам ищет факты через саб-агентов вместо того, чтобы
  спрашивать у пользователя то, что можно найти самому. Полезно перед редизайном
  секции лендинга: прогнать план через грилинг, а не молча предполагать.
- **Проверка безопасности:** только методичка в SKILL.md, без скриптов и внешних
  вызовов. Не запускалось ничего (`npm install`/`pip install`/скрипты).
