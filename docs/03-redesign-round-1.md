## 1. Два системных бага — ЧИТАТЬ ОБЯЗАТЕЛЬНО

### `overflow-x: clip` на `<html>` ломает переход по якорям

Стоял в `index.css` с комментарием «clip, а не hidden, иначе ScrollTrigger
меряет не тот скроллер». Побочный эффект оказался хуже: `clip` на корне ломает
нативный переход по якорям. Клик по «Цены» менял URL и не двигал страницу.

Проверено в консоли: снимаешь `overflow` — `scrollY` мгновенно 0 → 4807.

Горизонтальное переполнение давала только бегущая строка. Теперь клипается она,
а не корень документа.

### Токен `--spacing-block` ломал каждый `inline-block` на странице

Самый неочевидный баг проекта. В Tailwind v4 пространство имён `--spacing-*`
порождает не только `p-block`/`m-block`, но и логическое свойство
`inline-<value>` → `inline-size`. В скомпилированном CSS оказалось **две**
версии одного класса:

```css
.inline-block{display:inline-block}
.inline-block{inline-size:var(--spacing-block)}   /* = 72px на 1440px */
```

Вторая перебивала первую. Любой `inline-block` получал ширину 72px: бейдж в
hero обрезался до «Диагност», слова заголовка наезжали друг на друга.

Токен переименован в `--spacing-stack`. **Правило: имя spacing-токена не должно
совпадать с ключевым словом `display`** — `block`, `inline`, `flex`, `grid`,
`table`, `contents`.

## 2. Анимации

Причина, по которой пол-страницы висло на 30–70 % прозрачности, — обёртка
`AnimatedContent` (GSAP + ScrollTrigger). Таймлайн ставился на паузу и
проигрывался из `onEnter`; при быстром скролле он рвался и замирал навсегда.

**Заменено на `components/ui/Reveal.jsx`:** IntersectionObserver вешает два
класса, всё остальное делает CSS-анимация. Ключевое правило — *базовое
состояние элемента видимое*. Плюс страховка: если через 1.8 с блок во вьюпорте
всё ещё скрыт — показываем принудительно.

| Убрано в раунде 1 | Почему |
|---|---|
| `Aurora` (WebGL/ogl) | canvas на 70vh + бесконечный rAF |
| `AnimatedContent` (GSAP) | зависал на половине прозрачности |
| `SplitText` (GSAP) | ломал перенос заголовка на мобильном |
| `LogoLoop` (~15 КБ + rAF) | JS-цикл ради бегущей строки |
| `PillNav` (~15 КБ) | КАПС, GSAP на ховер, терял подпись активной пилюли |
| `ElectricBorder` | SVG-турбулентность каждый кадр, дрожащий край |
| `StarBorder` вокруг CTA | съедал доступное имя ссылки |

> **Примечание 07.08.2026.** Часть этого вернулась решением владельца 06.08:
> `SplitText` (GSAP) в hero, `FoldText` (GSAP) в блоке агентов,
> `FloatingLines` (WebGL/three) как фон первого экрана, `ScrollStack` (lenis).
> Вес бандла вырос до 893 КБ. Починено выносом three в отдельный чанк через
> `lazy()` — 410 КБ основной чанк. Следующие ~120 КБ — это GSAP, обе анимации
> заменимы на CSS.

## 4. Типографика

Флюидная шкала на `clamp()`, токены в `@theme`. Было → стало на 1440px:

| Было | Стало |
|---|---|
| 14px × 104 узла (весь основной текст) | 17px × 102 |
| 11–13px × 47 | 13–15px (только моно-лейблы и подписи) |
| 10px, 11px, 12px в интерфейсе | нет |
| инпуты формы 14px (iOS зумил) | 17px |
| прыжок 14 → 72px без ступеней | 13 / 15 / 17 / 20 / 21 / 26 / 44 / 48 / 68 |

Абзацы ограничены `max-w-[54ch]`…`[62ch]`. Межстрочный: 1.62 в тексте,
1.03–1.22 в заголовках, отрицательный трекинг на крупных кеглях.

Вертикальный ритм — два токена: `--spacing-section` (72→128px) и
`--spacing-stack` (40→72px). Никаких `py-20 md:py-28` вразнобой.

## 5. Про кейсы «якобы от крупных компаний»

Была просьба подписать выдуманные результаты именами реальных компаний.
Сделано не так, и вот почему.

Это, во-первых, введение в заблуждение, во-вторых, прямой риск: в РК это
недобросовестная реклама и использование чужого товарного знака, и любая из
этих компаний может потребовать снять упоминание. Для продукта, который продаёт
честность выводов, пойманная выдумка на главной убивает всё позиционирование
разом.

В коде — блок **«Что находим чаще всего»**: те же формулировки, но по отраслям
и без названий. Это правда, продаёт не хуже, и подписано «типовые находки, не
кейсы конкретных компаний».

Как появятся реальные кейсы с письменным согласием клиента — меняется один
массив `findings.items` в `site.js` и заголовок на «Кейсы».
