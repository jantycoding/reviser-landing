# Пошаговый запуск: GitHub → Vercel → домен → WhatsApp → реклама

Инструкция написана так, чтобы выполнять не думая, сверху вниз.
Каждый шаг заканчивается проверкой — не переходите дальше, пока она не прошла.

Кто что делает: **Ж** — Жантемир, **А** — Арсен, **ОБА** — вместе.

# Часть 1. GitHub

## Шаг 1.1 · Ж · Создать репозиторий

Аккаунт у Жантемира, поэтому репозиторий заводится под ним.

1. Открыть https://github.com/new
2. **Repository name:** `reviser-landing`
3. **Description:** `Лендинг Reviser — внедрение ИИ-агентов в бизнес`
4. **Private** — обязательно. Публичный репозиторий коммерческого проекта — это
   бесплатный доступ конкурентов к вашему тексту, структуре воронки и планам.
5. **Не** ставить галочки «Add a README», «Add .gitignore», «Choose a license».
   Всё это уже есть в проекте, и лишние файлы создадут конфликт при первом push.
6. Нажать **Create repository**

## Шаг 1.2 · Ж · Проверить, что git видит проект

В Терминале на маке:

```bash
cd ~/revisor-ai
git status
git log --oneline
```

Должно показать историю из нескольких коммитов. Если пишет
`fatal: not a git repository` — значит вы не в той папке.

## Шаг 1.3 · Ж · Убедиться, что секреты не уедут в GitHub

Это самый важный шаг во всей части. Проверьте до push, а не после.

```bash
git check-ignore -v .env
```

Должно ответить `.gitignore:3:.env    .env` или похоже — то есть файл
игнорируется. Если ответа нет вообще — **не пушьте**, сначала:

```bash
echo ".env" >> .gitignore
echo ".env.local" >> .gitignore
git rm --cached .env 2>/dev/null
git add .gitignore && git commit -m "Не пускаем .env в историю"
```

Ещё проверка — посмотреть, что вообще уйдёт:

```bash
git ls-files | grep -iE "\.env|token|secret|key" || echo "секретов в истории нет"
```

Если что-то нашлось — остановитесь и напишите мне, это чинится не одной командой.

## Шаг 1.4 · Ж · Связать с GitHub и запушить

Подставьте свой логин вместо `ЛОГИН`:

```bash
git remote add origin https://github.com/ЛОГИН/reviser-landing.git
git branch -M main
git push -u origin main
```

GitHub спросит логин и пароль. **Пароль от аккаунта не подойдёт** — с 2021 года
нужен токен:

1. https://github.com/settings/tokens → **Generate new token (classic)**
2. Note: `mac-reviser`, Expiration: 90 days
3. Отметить единственную галочку **`repo`**
4. **Generate token** → скопировать. Показывается один раз.
5. Вставить его вместо пароля при `git push`

Чтобы не вводить каждый раз:

```bash
git config --global credential.helper osxkeychain
```

**Проверка:** обновите страницу репозитория на GitHub — должны быть видны папки
`src`, `api`, `docs` и файл README с оформленным описанием.

## Шаг 1.5 · Ж · Добавить Арсена

Settings → Collaborators → **Add people** → логин Арсена → роль **Write**.

## Шаг 1.6 · ОБА · Как теперь работать вдвоём

Правило одно: **перед началом работы — `git pull`, после — `git push`.**

```bash
git pull                              # забрать чужие изменения
# ...правки через Claude Code...
git add -A
git commit -m "Цены: убрал тариф «План роста»"
git push
```

Сообщение коммита пишите так, чтобы через месяц было понятно, что вы искали.
`Цены: убрал тариф «План роста»` — хорошо. `fix`, `update`, `правки` — плохо.

Если `git push` ругается `rejected`, значит второй успел запушить раньше:

```bash
git pull --rebase
git push
```

**Не запускайте Claude Code на папке одновременно.** Пишите друг другу «беру
сайт на час» — буквально одно сообщение в чат. Git спасает от потери истории,
но не спасает от двух агентов, переписывающих один файл в реальном времени.

# Часть 2. Vercel и домен

## Шаг 2.1 · Ж · Подключить проект

1. https://vercel.com → **Continue with GitHub** (тем же аккаунтом)
2. **Add New → Project** → найти `reviser-landing` → **Import**
3. Vercel сам определит Vite. Проверьте, что стоит:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Раскрыть **Environment Variables** и добавить (пока без телеграма):

   | Name | Value |
   |---|---|
   | `VITE_WHATSAPP` | ваш номер: `77XXXXXXXXX` |
   | `VITE_EMAIL` | рабочая почта |
   | `VITE_INSTAGRAM` | ссылка на профиль |
   | `VITE_LEGAL` | `ИП Фамилия И.О. · ИИН 000000000000` |

5. **Deploy**

Через минуту получите адрес вида `reviser-landing.vercel.app`. Он рабочий —
можно показывать и тестировать до покупки домена.

**Проверка:** откройте адрес с телефона. Нажмите «Написать Reviser в WhatsApp» —
должен открыться чат с вашим номером.

## Шаг 2.2 · А · Купить домен

Что брать — по убыванию предпочтения:

| Вариант | Плюсы | Минусы |
|---|---|---|
| `reviser.kz` | доверие местного рынка, оплата в тенге, закрывающие на ИП | нужен ИИН/БИН, регистрация 1–3 дня |
| `reviser.ai` | совпадает с названием, «дорого» выглядит | ~$70–100/год, оплата картой |
| `reviser.io` / `.com` | нейтрально, покупается за минуту | вероятно занято |

Где покупать `.kz`: **ps.kz**, **hoster.kz**. Оба дают документы на ИП.
Где покупать международные: **Namecheap**, **Porkbun**, **Cloudflare Registrar**.

Одна проверка перед покупкой: вбейте название в поиск и в
https://gov.kz/memleket/entities/kazpatent — не занято ли имя товарным знаком
в вашем классе услуг. Пять минут сейчас дешевле, чем письмо от юриста потом.

## Шаг 2.3 · Ж · Привязать домен

1. Vercel → проект → **Settings → Domains** → ввести `reviser.kz` → **Add**
2. Vercel покажет, какие записи прописать. Обычно:

   | Тип | Имя | Значение |
   |---|---|---|
   | `A` | `@` | `76.76.21.21` |
   | `CNAME` | `www` | `cname.vercel-dns.com` |

   **Берите значения из интерфейса Vercel, а не отсюда** — они меняются.

3. Зайти в панель регистратора → DNS-записи → добавить обе
4. Вернуться в Vercel и подождать. Обновление DNS занимает от 10 минут до
   нескольких часов. SSL-сертификат Vercel выпустит сам, ничего платить и
   настраивать не нужно.

**Проверка:** `https://reviser.kz` открывается с замочком в адресной строке,
`http://` сам перекидывает на `https://`.

## Шаг 2.4 · Ж · Как теперь выкатываются изменения

Никак — само. Каждый `git push` в `main` собирает и выкатывает новую версию за
минуту. Откат: Vercel → Deployments → нужный деплой → «...» → **Promote to
Production**.

Полезное: если запушить не в `main`, а в отдельную ветку, Vercel соберёт
превью по отдельной ссылке. Удобно показывать друг другу правки до выкатки.

# Часть 3. WhatsApp

## Что нужно понимать до настройки

Вы выбрали **обычное приложение WhatsApp Business**. Это нормальный старт, но у
него есть жёсткое ограничение, которое сейчас противоречит тексту на сайте.

**Приложение WhatsApp Business не умеет работать ботом.** Оно умеет:
- приветственное сообщение — уходит автоматически на первое сообщение от нового
  контакта;
- сообщение «нет на месте» — по расписанию;
- быстрые ответы — заготовки, которые вставляете вы, вручную;
- каталог, метки, статистика.

Оно **не** умеет: вести диалог, задавать уточняющие вопросы по логике,
проверять код оплаты, собирать анкету. Всё это делает человек.

Сайт сейчас обещает другое. В `src/content/site.js` написано:
`Пишете Reviser в WhatsApp с кодом. Он спрашивает о бизнесе и присылает список
доступов`, `phoneLabel: 'ИИ-ассистент'`, в hero — «Написать Reviser в WhatsApp»
с подписью, что это и есть ваш агент.

Клиент, купивший разбор у команды ИИ-агентов, напишет в WhatsApp и увидит
человека. Это не мелочь: первое же взаимодействие с продуктом опровергает
главное обещание страницы.

**Развилка — решать до запуска рекламы:**

| Вариант | Что делать | Цена решения |
|---|---|---|
| **A. Поправить текст** | Убрать «агент ответит», написать «отвечаем в течение 15 минут». Честно и запускается сегодня | Слабее оффер, но ничего не ломается |
| **B. WhatsApp Cloud API** | Официальный API Meta. Бесплатно до 1000 диалогов в месяц. У Арсена уже есть Meta Business через RB Clinic | 1–2 дня настройки + нужен бэкенд для логики бота |

Мой совет: **на первую неделю — A, со второй — B.** Первые 10 клиентов вы всё
равно ведёте руками (иначе не поймёте, где рвётся конвейер), так что бот пока
ничего не ускорит, а обещание, которое вы не держите, обойдётся дороже.

Важная деталь про переход на B: номер, подключённый к Cloud API, **перестаёт
работать в приложении**. Поэтому под API берите второй номер, а первый оставьте
как есть.

## Шаг 3.1 · А · Подготовить номер

1. Отдельная SIM, не личная. Номер уйдёт в рекламу, на сайт и в чеки — менять
   его потом дорого.
2. Установить **WhatsApp Business** (не обычный WhatsApp), зарегистрировать номер
3. Заполнить профиль: название `Reviser`, категория, описание, сайт, адрес почты
4. Настроить автоответы: **Настройки → Инструменты для бизнеса**
   - **Приветственное сообщение** — уходит новому контакту автоматически.
     Текст должен закрывать первую минуту ожидания:

     > Здравствуйте! Это Reviser. Получили вашу заявку на разбор бизнеса за
     > 9 900 ₸. Отвечаем с 9:00 до 21:00, обычно в течение 15 минут.
     > Пока ждёте — можете сразу написать, чем занимается ваш бизнес и сколько
     > примерно заявок в месяц.

   - **Сообщение «Нет на месте»** — на нерабочие часы, с честным сроком ответа
   - **Быстрые ответы** — заготовьте минимум четыре: реквизиты для оплаты,
     список доступов, текст NDA, «отчёт будет такого-то числа»

## Шаг 3.2 · Ж · Прописать номер на сайте

Формат критичен: **только цифры**, международный формат, без `+`, пробелов,
скобок и дефисов. Казахстан: `77011234567`.

`+7 (701) 123-45-67` → `77011234567`

Vercel → Settings → Environment Variables → `VITE_WHATSAPP` → сохранить →
**Deployments → последний → Redeploy**. Переменные подхватываются только при
новой сборке, само не обновится.

Локально то же самое пишется в `.env`.

**Проверка (обязательно с телефона, а не с компьютера):**
1. Открыть сайт, долистать до блока оплаты
2. Ввести имя и телефон, нажать кнопку
3. Должен открыться WhatsApp с вашим номером и **уже набранным** текстом:
   «Здравствуйте! Хочу разбор бизнеса за 9 900 ₸. Меня зовут … Телефон: …»
4. Отправить. Должно прийти приветственное сообщение из шага 3.1

Если открылся чат с пустым полем ввода — номер записан в неверном формате.
Если WhatsApp не открылся вовсе — в номере остались плюс или пробелы.

## Шаг 3.3 · Ж · Чтобы заявки не терялись

Переход в WhatsApp — это ещё не сообщение. Человек может не нажать «отправить»,
отвлечься при переключении приложений, или у него не стоит WhatsApp на
компьютере. Имя и телефон он уже ввёл — их нужно сохранить в любом случае.

Код для этого уже написан: `api/lead.js` + `src/lib/track.js`. Осталось создать
бота и вписать два секрета.

**Создать бота:**
1. Telegram → найти **@BotFather** → `/newbot`
2. Имя: `Reviser Заявки`, username: `reviser_leads_bot` (должен заканчиваться на `bot`)
3. BotFather пришлёт токен вида `7123456789:AAH…` — это секрет, не публикуйте его

**Узнать id чата:**
1. Создать группу, например «Reviser · заявки»
2. Добавить туда бота и Арсена
3. Написать в группу любое сообщение
4. Открыть в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
5. Найти `"chat":{"id":-1001234567890` — это и есть `TELEGRAM_CHAT_ID`.
   **У групп id отрицательный, минус — часть id.**

**Вписать в Vercel:**

Settings → Environment Variables → добавить **без** префикса `VITE_`:

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | `-1001234567890` |

Почему без `VITE_`: всё с этим префиксом вшивается в JS и читается любым
человеком через «Просмотр кода». С вашим токеном можно писать от имени бота.

Redeploy.

**Проверка:** заполнить форму на сайте → в группу должно упасть сообщение
«Заявка с сайта Reviser» с именем и телефоном. Если не упало — Vercel → проект
→ **Logs**, там будет причина.

# Часть 4. Meta Pixel

Без него Meta не умеет оптимизировать закупку: алгоритм показывает рекламу
«похожим на тех, кто конвертировался», а не зная, кто конвертировался, он
оптимизирует на клики. Разница в цене заявки — обычно в разы.

## Шаг 4.1 · А · Создать пиксель

1. https://business.facebook.com → **Events Manager** → **Connect Data Sources**
   → **Web** → **Meta Pixel**
2. Назвать `Reviser Landing`
3. Скопировать **Pixel ID** — 15–16 цифр
4. Способ установки выбирать не нужно: код уже в проекте

## Шаг 4.2 · Ж · Включить

Vercel → Environment Variables → `VITE_META_PIXEL_ID` = ваш id → Redeploy.

Пока переменная пустая, пиксель вообще не грузится — ни одного запроса к
`facebook.net` на странице. Это сделано специально: локальная разработка не
должна засорять статистику кабинета.

## Шаг 4.3 · А · Проверить и настроить

1. Поставить расширение **Meta Pixel Helper** в Chrome
2. Открыть сайт — Helper должен показать `PageView`
3. Заполнить форму, нажать кнопку — должны появиться `InitiateCheckout` и `Lead`
4. Events Manager → **Aggregated Event Measurement** → приоритеты событий:
   `Lead` первым, `InitiateCheckout` вторым, `Contact` третьим
5. В кампаниях оптимизироваться на **Lead**

Какие события уже настроены:

| Событие | Когда срабатывает |
|---|---|
| `PageView` | открытие страницы |
| `InitiateCheckout` | клик по кнопке в блоке оплаты |
| `Lead` | тот же клик, но только если оставлены имя или телефон |
| `Contact` | клик по WhatsApp в hero, FAQ, подвале |

`Lead` намеренно не вешается на все клики по WhatsApp: пометив им кнопку в
подвале, вы научите алгоритм искать любопытных вместо покупателей.

# Часть 5. Довести лендинг до состояния «можно лить трафик»

Порядок по важности. Не переходите к следующему, пока не закрыт предыдущий.

## 5.1 · А · Снять стоп-маркер в контактах ⛔️

В `src/content/site.js` стоит явное предупреждение, и оно честное. Пока в
переменных заглушки, все кнопки WhatsApp на странице ведут в никуда — а это
четыре разных места, включая первый экран.

Закрывается заполнением `VITE_WHATSAPP`, `VITE_EMAIL`, `VITE_INSTAGRAM`,
`VITE_LEGAL` в Vercel (шаг 2.1).

Отдельно про `VITE_LEGAL`: строка вида «ИП Фамилия И.О. · ИИН 000000000000»
берётся из договора-оферты. Заглушка в реквизитах хуже их отсутствия — она
превращает недосказанность в прямую ложь.

**Готово, если:** на сайте нет ни одного `77000000000`, `hello@reviser.ai` и
пустой ссылки на инстаграм.

## 5.2 · А · Картинка для превью ссылки

`index.html` ссылается на `/og.png`, файла нет. Любая ссылка на сайт,
отправленная в WhatsApp, инстаграм или телеграм, покажет пустой прямоугольник.
Для продукта, который распространяется пересылкой ссылки, это дорого.

Нужен файл **1200×630 px**, положить в `public/og.png`.

Что на нём: логотип, одна фраза из hero, цена. Без мелкого текста — в ленте
картинка показывается размером примерно с спичечный коробок.

**Проверка:** после выкатки прогнать адрес через
https://developers.facebook.com/tools/debug/ → **Scrape Again**.

## 5.3 · ОБА · Решить вопрос гарантии возврата

В FAQ висит с 5 августа с пометкой TODO: обещаете ли вернуть деньги, если в
отчёте не окажется ни одной находки.

Это обещание с юридическими последствиями. Два честных варианта:

- **Даёте** — формулировка идёт в договор-оферту, а не только на сайт. Условия
  прописать точно: срок, кто принимает решение, что считается «не нашли».
- **Не даёте** — убрать пункт из FAQ целиком. Обещание без юридической опоры
  хуже, чем его отсутствие: первый же спор вы проиграете дважды — деньгами и
  публично.

## 5.4 · А · Привести обещания в соответствие с реальностью

Пройдите по странице и проверьте каждую цифру. Всё, что не подтверждено
реальным разбором на RB Clinic, — либо меняйте, либо убирайте.

| Что обещано | Где | Чем подтверждается |
|---|---|---|
| 3 рабочих дня до отчёта | `stats` | ? |
| 12 направлений в разборе | `stats`, `audit` | ? |
| ~1 час вашего времени | `stats`, `process` | ? |
| 0 паролей, только гостевой доступ | `stats`, FAQ | ✓ решение принято |
| 8 сценариев агентов | `agents.items` | ? что из этого вы умеете |
| Внедрение от 600 000 ₸ | `pricing` | ? откуда цифра |
| Тариф «План роста» 6 900 ₸ | `pricing` | ? кто его купит |
| Консалтинг: 3–6 недель, от 300 000 ₸ | `compare.rows` | оценка рынка, проверить |

Правило простое: цифра, которую вы не можете объяснить клиенту на созвоне, не
должна стоять на странице.

## 5.5 · А · Поправить текст под реальный WhatsApp

Если выбрали вариант A из части 3 — эти строки в `site.js` обещают бота,
которого нет:

- `contacts.phoneLabel: 'ИИ-ассистент'`
- `process.steps[1]`: «Пишете Reviser в WhatsApp с кодом. **Он спрашивает** о
  бизнесе и присылает список доступов»
- `faq.lead`: «напишите Reviser в WhatsApp, **он ответит сразу**»
- `hero.secondaryCta`: «Написать Reviser в WhatsApp»

Замена не ослабляет оффер, если давать конкретику вместо расплывчатого
«ответим»: «отвечаем за 15 минут с 9:00 до 21:00» продаёт не хуже, чем «агент
ответит сразу», и не разваливается при первом же контакте.

## 5.6 · Ж · Прогнать страницу целиком

С телефона, как клиент, от начала до конца:

- [ ] все семь пунктов меню доскраливают до своего раздела
- [ ] быстрый скролл сверху донизу — нет пустых экранов и застрявших блоков
- [ ] все четыре кнопки WhatsApp открывают чат с готовым текстом
- [ ] форма: Enter в поле телефона работает так же, как тап по кнопке
- [ ] заявка падает в телеграм
- [ ] Pixel Helper показывает `Lead`
- [ ] FAQ раскрывается и сворачивается
- [ ] ссылка, отправленная себе в WhatsApp, показывает картинку превью
- [ ] страница открывается за 2–3 секунды на мобильном интернете, а не на вайфае

## 5.7 · ОБА · Посчитать экономику до первого тенге в рекламу

Это не про сайт, но именно здесь решается, работает ли бизнес.

Разбор стоит 9 900 ₸. Себестоимость — токены плюс 20 минут аналитика.
Если лид стоит дороже 3 000 ₸, разбор сам по себе в минус, и окупается он
только допродажей внедрения.

Посчитайте до заливки бюджета: при какой конверсии «разбор → внедрение за
600 000 ₸» сходится юнит-экономика. Если получается, что нужен каждый десятый —
это одна стратегия и один темп. Если каждый третий — другая, и рекламу лучше
не включать, пока не проверите на первых пяти клиентах вручную.

# Приложение. Что делать, когда что-то сломалось

| Симптом | Где смотреть |
|---|---|
| Сайт не собирается на Vercel | Vercel → Deployments → упавший → **Building** |
| Собрался, но страница белая | консоль браузера (F12 → Console) |
| Заявка не падает в телеграм | Vercel → **Logs** → фильтр `lead:` |
| Кнопка WhatsApp ведёт не туда | Vercel → Environment Variables → `VITE_WHATSAPP`, потом **Redeploy** |
| Изменил переменную, ничего не поменялось | переменные подхватываются только при новой сборке — нужен Redeploy |
| Пиксель не видит событий | `VITE_META_PIXEL_ID` не задан, или блокировщик рекламы в браузере |
| Всё сломалось после правок | Vercel → Deployments → рабочий деплой → **Promote to Production**, потом `git revert` |

Откат кода локально:

```bash
git log --oneline          # найти хеш рабочего коммита
git revert <хеш>           # создаёт обратный коммит, историю не ломает
git push
```

`git reset --hard` не используйте: он стирает историю, и если вы уже
запушили — вы сломаете работу второго.
