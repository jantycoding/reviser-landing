# Reviser — контекст проекта

Лендинг и будущая система аудитов для Reviser. Читай этот файл перед любой
работой в репозитории.

## Бизнес в двух абзацах

Продаём **внедрение ИИ-агентов в бизнес**. Это оффер, посыл всех креативов и то,
за чем приходит человек с рекламы в инстаграме.

**Аудит бизнеса за 14 990 ₸** — первое касание и основной источник дохода.
Логика: нельзя внедрить агента в бизнес, который не изучен, поэтому аудит —
обязательный первый шаг, а не допродажа. Через конвейер проходит много бизнесов
дёшево, во внедрение (от 600 000 ₸) берутся единицы. Между ними — план роста
за 6 900 ₸ и точечные услуги.

Ключевое следствие для сайта: он продаёт **импульсную покупку аудита прямо на
странице**, а не собирает заявки.

## Стек

Vite 8 · React 19 · Tailwind v4 (токены в `@theme` внутри `src/index.css`, конфига нет).
Весь текст страницы — в `src/content/site.js`, компоненты текста не содержат.

```
npm run dev      # разработка
npm run build    # сборка
npm run lint     # oxlint
```

## Скиллы

В `.claude/skills/` лежат скиллы Anthropic (`github.com/anthropics/skills`) и два
собственных:

- **`reviser-landing`** — дизайн-система сайта, структура воронки и две ловушки,
  которые уже ломали проект. **Читать перед любой правкой в `src/`.**
- **`reviser-audit`** — методика аудита: 12 направлений, схема находки в JSON,
  деление «агент / своими силами», экономия токенов.

Из внешних чаще всего понадобятся: `frontend-design` (визуальные решения),
`webapp-testing` (проверка страницы), `pdf` (отчёт — это PDF-продукт),
`skill-creator` (новые скиллы под процессы), `mcp-builder` (коннекторы к CRM и
рекламным кабинетам для агентов), `claude-api` (система агентов).

## Инструменты проверки React

Порядок применения: линтер → doctor → браузер.

```
npm run lint         # oxlint, как и раньше — основной линтер
npm run lint:hooks   # eslint-plugin-react-hooks: exhaustive-deps + правила React Compiler
npm run doctor       # react-doctor: 400+ правил (эффекты, перф, a11y, безопасность)
```

- **react-doctor** стоит ещё и скиллом в `.claude/skills/react-doctor` — агент
  чинит найденное сам. Хук `.git/hooks/pre-commit` предупреждает о регрессиях,
  но коммит не блокирует. В CI — `.github/workflows/react-doctor.yml`,
  проверяется только то, что изменено, а не весь бэклог.
- **React Scan** подключён в `src/main.jsx` под `import.meta.env.DEV` — показывает
  лишние ре-рендеры прямо в `npm run dev` и в прод не попадает.

MCP-серверы перечислены в `.mcp.json`, при первом запуске Claude Code в папке их
надо подтвердить один раз:

- **context7** — доки под конкретную версию. React 19 и Vite 8 свежие, без него
  модель пишет по памяти и промахивается. Включается словами `use context7`.
- **playwright** — открыть страницу в реальном браузере и проверить поведение,
  а не только то, что сборка прошла.
- **shadcn** — реестр компонентов React Bits, прописан в `components.json` →
  `registries`. Через него можно искать и читать исходники всех компонентов.
  В реестре у каждого компонента 4 варианта, нам нужен **`-JS-TW`** (проект на
  JSX + Tailwind), например `@react-bits/Aurora-JS-TW`. Часть компонентов уже
  вендорена в `src/components/reactbits/` — сначала смотреть туда.

Алиас `@/` → `src/` (`vite.config.js` + `jsconfig.json`) добавлен ради реестра
shadcn; существующие относительные импорты не переписывались.

## Красные линии

Это не стилистические предпочтения, а вещи, которые ломают бизнес или сайт.

1. **Не выдавать чужие логотипы за своих клиентов** и не приписывать компании
   несуществующую историю. Трафик идёт из Meta, ложные заявления о компании —
   прямое нарушение рекламной политики и бан аккаунта. Лента на сайте — это
   платформы, к которым мы подключаемся.
2. **Не просить у клиентов пароли.** Только гостевой доступ на чтение. Передача
   учётных данных запрещена условиями Meta, amoCRM и Bitrix и ведёт к блокировке
   обоих аккаунтов. На сайте это заявлено как преимущество.
3. **Не ставить `overflow-x` на `<html>`** — ломает якорную навигацию.
4. **Не называть spacing-токены ключевыми словами `display`** (`block`, `inline`,
   `flex`, `grid`) — Tailwind v4 сгенерирует конфликтующий класс.
5. **Базовое состояние элемента — видимое.** Прятать имеет право только код,
   который гарантированно покажет обратно.
6. **Никаких выдуманных фактов в отчётах клиентам.** Нет данных — так и писать.
7. **Никаких дев-инструментов через CDN в `index.html`.** Установщики любят
   вписать туда `<script src="https://unpkg.com/...">` — такой скрипт грузится у
   каждого посетителя рекламного трафика. Профайлеры подключать только локальным
   пакетом и под `import.meta.env.DEV`.

## Структура

```
src/
  content/site.js        весь текст страницы + цены + контакты
  index.css              токены @theme, ритм, анимации, утилиты
  lib/track.js           отправка заявки в api/lead.js + события Meta Pixel
  components/
    Header.jsx           навигация со скролл-спаем
    agents/
      AgentSwarm.jsx     демо-панель отчёта с курсорами агентов
      Claudik.jsx        Клодик — SVG-маскот агента, роль задаётся цветом
    ui/                  Section, Reveal, Marquee, Logo, PriceUsd
    reactbits/           вендорные компоненты (используются не все)
  sections/              Hero → Agents → Platforms → Gate → Audit →
                         Report → Process → Pricing → Faq → Checkout,
                         плюс Footer
api/lead.js              serverless-функция: заявка с формы → телеграм
```

`_backup_*` и `_to_delete` — временные папки, в работе не участвуют.
