# Revisor AI — лендинг

Одностраничный лендинг: React + Vite + Tailwind v4, анимации на компонентах
[react-bits](https://github.com/DavidHDev/react-bits).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # соберёт в dist/
npm run preview  # посмотреть собранную версию
```

## Где менять текст

Весь текст лендинга лежит в **`src/content/site.js`** — заголовки, блоки,
тарифы, FAQ, контакты. Компоненты трогать не нужно.

В файле помечено `TODO` то, что нужно проверить перед публикацией:

| Что | Где | Почему |
| --- | --- | --- |
| Телефон, WhatsApp, почта, Instagram | `contacts` | стоят заглушки |
| Реквизиты в футере | `contacts.legal` | заглушка |
| Цена «Углублённый анализ» — 49 000 ₸ | `pricing.plans[1].price` | цену вы не называли, поставлена для примера |
| Цифры про консалтинг (3–6 недель, от 300 000 ₸) | `compare.rows` | это оценка рынка, проверьте |
| Возврат денег, если ничего не найдём | `faq.items[3]` | это обещание клиенту — решите, даёте ли вы его |

Цифры в блоке под первым экраном (`stats`) — характеристики продукта
(12 направлений, 3 дня, 9 900 ₸), а не результаты клиентов. Пока нет реальных
кейсов, так их и стоит держать.

## Куда уходит заявка

Форма работает без бэкенда:

- если задан `VITE_FORM_ENDPOINT` — отправит JSON туда (Formspree, Telegram-бот, свой webhook);
- если не задан — откроет WhatsApp с уже заполненным текстом заявки.

Скопируйте `.env.example` в `.env` и подставьте свои значения.

## Деплой

Собирается в статику, подойдёт любой хостинг:

```bash
npm run build
```

Дальше папку `dist/` — на Netlify (можно просто перетащить в веб-интерфейс),
Vercel или GitHub Pages. Переменные из `.env` продублируйте в настройках хостинга.

## Компоненты react-bits

Исходники скопированы в `src/components/reactbits/` — так и предполагается в
react-bits, это не npm-зависимость. Используются: `Aurora`, `PillNav`,
`SplitText`, `ShinyText`, `CountUp`, `SpotlightCard`, `AnimatedContent`,
`StarBorder`, `ElectricBorder`, `CardSwap`, `LogoLoop`.

Что отличается от оригинала (правки помечены комментариями в коде):

- **`PillNav.jsx`** — убрана зависимость от `react-router-dom` (сайт одностраничный),
  добавлен проп `logoHref`, корень сделан `relative` вместо `absolute`.
- **`SplitText.jsx`** — убран `overflow-hidden`: он обрезал вторую строку
  многострочного заголовка.
- Проект рендерится **без `<StrictMode>`** (`src/main.jsx`). В StrictMode React
  монтирует эффекты дважды, и GSAP-компоненты react-bits дублируют разбитый
  текст — слова наезжают друг на друга. Сам react-bits тоже рендерится без него.
